# Vigia IA 1.0.109+109

## Resumo

Esta entrega adiciona um atalho global para controlar o mini mapa diretamente no monitor Ao vivo, sem depender do modo Bike e sem precisar abrir o painel de preferências.

## Alterações

- adicionado item **Mostrar mapa** no menu dos três pontinhos quando o mapa não está visível;
- adicionado item **Ocultar mapa** no mesmo menu quando o mapa está visível;
- adicionado item **Mapa automático** quando a visibilidade foi forçada para **Sempre** ou **Ocultar**;
- a escolha continua persistida em `MapRouteService`, preservando consistência entre retrato, paisagem, multicâmera e tela inteira;
- sincronizados metadados, Mudanças, README, CHANGELOG, arquitetura, validação e testes para a nova versão.
