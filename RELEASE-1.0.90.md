# Vigia IA 1.0.90+90

## Resumo

Esta entrega ajusta a tela vertical do Ao vivo para ficar mais próxima do layout ilustrado: câmera maior, mapa presente também em retrato e atalhos reorganizados para não esmagar a área útil.

## Principais mudanças

- Redesenho da tela vertical do monitor.
- Câmera com altura adaptada à proporção real da prévia.
- Mini-mapa integrado ao retrato com rota, distância e controles rápidos.
- Ações horizontais para detectar, mostrar mapa, áudio, painel e ajustes.
- Painel avançado sob demanda com áreas, objetos, regras, fonte, segunda câmera e recursos.

## Compatibilidade

- O dashboard em paisagem continua ativo.
- O mapa completo segue disponível em `MapMonitoringScreen`.
- A integração com GPS continua sem exigir API para o funcionamento básico via OpenStreetMap.
